## Validation environment and evidence

Local tests use Python 3.11.16 and 3.12.14, an isolated disposable Redis 7 container, and cached `BAAI/bge-small-en-v1.5` weights at revision `5c38ec7c405ec4b44b94cc5a9bb96e735b38267a`. Package dependencies are locked in `uv.lock`. The existing non-test Redis service is not used for cleanup or fixture data.

- The untouched v0.1.1 archive passed 165 tests; four model tests were not enabled for that baseline run.
- The v0.2 full suite passed **372 tests with zero skips** on each supported interpreter, including real Redis and real-model tests. Three FAISS import deprecation warnings remain.
- Ruff lint and formatting, strict documentation build, lockfile consistency, distribution metadata checks, and the offline public-interface example are required final local checks.
- A real Python 3.10 installer rejects the built wheel through `Requires-Python >=3.11`; this is checked against the actual artifact, not a version override.
- Dependency-resolved clean-wheel installation uses the same CPU Torch build as the lockfile. An unconstrained wheel install may select a different PyPI Torch build because installer index configuration is not wheel metadata.

The sandbox prevents normal async wakeup sockets. Async/model/Redis validation therefore ran outside that sandbox; there is no event-loop workaround or sandbox-only monkeypatch in product code or tests.

## Evaluation evidence and limits

The frozen synthetic protocol contains 2,000 safe paraphrases, 2,000 near misses, 500 scope/context changes, 200 unsupported/missing-identity requests, and 100 freshness/lifecycle cases. It uses 35 held-out operation families for safe paraphrases, expanded with account identifiers. Expanded variants are correlated.

The recorded run accepted 2,000 hits with zero incorrect hits, 100% safe-paraphrase coverage, zero isolation/freshness errors, and 100% unsupported-case bypasses. The one-sided 95% Clopper–Pearson upper bound is approximately 0.15% under its independence assumption; correlation means this must not be presented as a universal error bound. All configured synthetic gates passed.

The v0.1.1 semantic-only comparison used identical real-model vectors and threshold. It accepted 3,500 of 4,000 deliberately adversarial semantic cases, including 1,500 incorrect hits. This characterizes this synthetic test set, not a production error rate or a claim about every v0.1.1 deployment.

Full JSON/Markdown evidence lives in `evaluation/reports/` in the repository and is uploaded by CI. Scenario latency uses precomputed real-model vectors and excludes model inference. The separate `evaluation.performance` benchmark includes real embedding inference and compares warm hits at 1K/10K entries, with flat and HNSW indexes, 50 timed samples each, and one Torch/FAISS thread. All four paired comparisons passed `v0.2 p95 <= 1.2 × v0.1.1 p95 + 5 ms`.

### Latency protocol correction

Sequential old/new runs produced inconsistent failures, including one run without concurrent test jobs. The isolated 10K-entry probe measured non-embedding p95 overhead of 2.337 ms while direct model-inference p95 varied to 37.502 ms. This supported inference-time drift as a confound rather than a 20 ms cache-policy regression.

The benchmark now uses `paired-warm-hit-v2`: separate real v0.1.1/v0.2 workers alternate sample order using the same immutable model snapshot. Both indexes are prepared before warming and timing; garbage collection remains enabled; IPC overhead is excluded. The sample count and acceptance formula were unchanged. A deterministic clock-drift regression test protects this pairing. The original contended and standalone failed runs are preserved as diagnostic-only artifacts, and the final paired run reports embedding and non-embedding timing separately. Synthetic distractors measure index-size overhead rather than production retrieval quality.

## Upgrade and rollback

The supported upgrade uses a fresh SQLite path or versioned Redis generation. Legacy metadata is not inferred or relabeled. The legacy SQLite test verifies that refusal leaves the old file unchanged. Reopening format-2 state with a different embedding revision fails before reuse; same-size models are not assumed compatible.

Restore the preserved v0.1.1 environment/store for rollback. Cache scope is a library contract; possession of database/process credentials is trusted access. See [migration](../migration-v0.2.md) for operational details.
