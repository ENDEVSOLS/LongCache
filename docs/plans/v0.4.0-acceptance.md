The refreshed local full-suite run on Python 3.12 with Redis 7.2.17 and the pinned model enabled passed **476 tests with zero skips**. See the [execution record](v0.4.0-execution.md) for the precise run and limitations.

**Still required before release:** repeated multi-process fault and reconnect stress; bounded invalidation and cleanup under load; full lease timeout/cancellation/renewal matrix; mixed sync/async distributed requests; Python 3.11 installed-wheel coverage and a full installed-wheel matrix; controlled-host scale/latency/recovery budgets; dependency-size and NumPy compatibility investigation; hosted CI and release-candidate feedback. The detailed gates are in the [plan](v0.4.0.md).
