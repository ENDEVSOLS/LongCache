## Performance-driven refinements

The first smoke run exposed a distinct-sync-miss throughput regression (162.35/s
versus 186.26/s baseline at concurrency 20). It is retained here as a diagnostic
summary, not accepted release evidence. The original measured p95 values were
117.44 ms versus 101.36 ms with a 100 ms origin stub.

The implementation now skips embedding when the index is empty and rechecks the
leader's stored entry directly on shared replay instead of repeating vector search.
Admission, verification, codec, identity, payload integrity, TTL, and invalidation
checks remain mandatory. Initialized async calls join before searching; the leader
performs the post-join lookup once and followers observe it through completion.
Slow cache work still runs in tracked workers. A registry epoch closes registration
races with invalidation. This refines the plan's illustrative per-caller sequence.

Queued cancellation retains its capacity slot until dequeue. This prevents repeated
cancel/resubmit loops from accumulating cancelled executor work items. Shutdown
resource failure remains visibly CLOSING rather than claiming CLOSED.

The local paired deterministic warm report is
`evaluation/reports/v0_3_reliability-local.json` and its Markdown companion. It uses
the archived actual v0.2 source at `6a059e7`, one FAISS thread, five alternating
repeats, and 10,000 warm samples per cell/version. This run precedes packaging and
records its own source hashes; it is not an artifact-publication claim.

## Final resource review

Async flight waits use detachable loop-local subscriptions. Repeated timeouts do not
leave callbacks attached to a long-running concurrent future. Concurrent `aclose`
callers share one owned cleanup worker across loops, so cancelled close callers do
not accumulate default-executor jobs. Deadline failures remain visible even if the
resulting cancellation finishes cleanup before an async waiter resumes.

Hosted CI, controlled performance measurements, candidate feedback, and publication
remain separate from local implementation evidence.
